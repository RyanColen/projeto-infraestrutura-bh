# Licença e atribuição dos dados geográficos

Este projeto utiliza dados geográficos disponibilizados pela Prefeitura de Belo Horizonte (PBH), por meio do Portal de Dados Abertos. As páginas dos três conjuntos indicam **Creative Commons Attribution**. A versão numérica da licença não foi especificada nas páginas consultadas; não se presume CC BY 4.0.

## Condições e atribuição

A reutilização deve respeitar os termos indicados em cada conjunto, manter atribuição apropriada à Prefeitura de Belo Horizonte e aos órgãos responsáveis, citar a fonte e identificar as modificações realizadas. Os dados originais não são de autoria dos desenvolvedores deste projeto.

A licença MIT do arquivo `LICENSE` aplica-se somente ao código, scripts e demais contribuições originais do repositório. Ela não substitui nem altera as licenças dos dados geográficos da PBH.
